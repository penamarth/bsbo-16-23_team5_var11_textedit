### Сохранение файла в разных форматах
1. Пользователь (U)Инициирует экспорт,"В интерфейсе выбирает экспорт и указывает формат pdf. Вызывается E.export(format: "pdf").
2. Editor (E) Обращается к Фабрике для создания нужного алгоритма сохранения: EF.createStrategy("pdf").
3. ExportStrategyFabric (EF) создает стратегию: создает конкретный объект Pd ExportStrategy (ES) и возвращает его Editor.
4. Editor (E), делегирует задачу Менеджеру: передает стратегию и документ для вы олнения: EM.export(strategy: ES, doc: D).
5. ExportManager (EM) исполняет стратегию: определяет путь сохранения (напр., pa h: String) и делегирует сохранение стратегии: ES.export(doc: D, path: St ing).
6. PdfExportStrategy (ES) запрашивает данные: чтобы получить содержимое для со ранения, обращается к структуре документа: D.getComponents().
7. Document (D), предоставляет данные: возвращает свою структуру компонентов (L st<IComponent>), позволяя стратегии обходить дерево Composite.
8. PdfExportStrategy (ES) выполняет сохранение: Обрабатывает полученные данные, фо матирует их как PDF и сохраняет файл по указанному пути.
9. ES → EM → E. Результат успешного сохранения возвращается по цепочке обратно к Editor.
10. Editor (E) показывает уведомление: «Экспорт успешно завершен».

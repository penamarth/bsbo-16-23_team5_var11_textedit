### Сохранение файла в разных форматах
1. Пользователь вызывает метод export(format_str) у Editor, указывая желаемый формат.
2. Editor обращается к ExportStrategyFabric (Фабрике) через метод create_strategy(format_str).
3. ExportStrategyFabric определяет формат и создает соответствующий объект стратегии (PdfExportStrategy или JsonExportStrategy).
4. ExportStrategyFabric возвращает созданный экземпляр стратегии обратно в Editor.
5. Editor вызывает ExportManager, передавая ему полученную стратегию и текущий документ через метод export(strategy, doc).
6. ExportManager вызывает метод export(doc, path) у переданной Стратегии.
7. Стратегия обращается к Document, вызывая get_components(), чтобы получить содержимое для экспорта.
8. Document возвращает список компонентов (content list).
9. Стратегия обрабатывает полученные данные, формирует файл и возвращает результат (путь или файл) в ExportManager.
10. ExportManager возвращает результат выполнения в Editor.
11. Editor отправляет сообщение Пользователю о том, что экспорт завершен.

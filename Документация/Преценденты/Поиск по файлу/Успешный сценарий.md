### Успешнй сценарий: Поиск по тексту

Предусловие: Документ открыт, содержит текст.

1. Инициация: Пользователь вводит поисковый запрос (например, "data") и выбирает настройки (например, "whole word").

2. Настройка стратегии: Editor инициализирует объект SearchHighlighter, передавая ему параметры поиска.

3. Запуск обработки: Editor вызывает метод highlight(document) у хайлайтера.

4. Обход дерева компонентов: SearchHighlighter запрашивает структуру документа: Document -> ParagraphComponent -> SentenceComponent -> WordComponent.

5. Анализ слов:
   - Хайлайтер проверяет содержимое каждого слова.
   - При совпадении: Вызывается метод setBackColor("orange") у объекта WordComponent.
   - При отсутствии совпадения: Вызывается метод setBackColor("none"), чтобы очистить старые результаты поиска.

6. Визуализация: После завершения поиска Editor вызывает метод viewText() у объекта Document.

7. Результат: Документ самостоятельно отрисовывает свое содержимое, отображая слова с учетом их цвета шрифта и установленного цвета фона.

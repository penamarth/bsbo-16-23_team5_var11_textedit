### Успешный сценарий: Поиск по тексту

Актер: Пользователь Предусловие: Приложение запущено, документ создан или открыт, в тексте есть содержимое.

1. Запрос поиска: Пользователь выбирает в меню команду поиска («Найти и подсветить»).

2. Ввод параметров: Система запрашивает искомый текст. Пользователь вводит слово (например, "data") и указывает параметры (например, «Искать только слово целиком»).

4. Обработка: Система сканирует весь документ на наличие совпадений.

5. Визуализация результата:

   - Система отображает документ, где все найденные слова выделены цветным фоном (например, оранжевым).

   - Важно: Исходный цвет текста (например, синяя подсветка кода) сохраняется. Пользователь видит текст, который одновременно является и цветным кодом, и выделенным результатом поиска.

6. Завершение работы с поиском: Пользователь выбирает команду просмотра («Показать содержимое»).

7. Сброс: Система убирает фоновое выделение поиска. Документ возвращается к своему обычному виду (видна только синтаксическая подсветка).

### Успешный сценарий: Поиск по тексту

Предусловие: Приложение запущено, документ открыт и содержит текст.

1. Инициация поиска: Пользователь вызывает команду поиска через меню интерфейса (например, нажимает кнопку «Найти»).

2. Настройка параметров: Система отображает поле для ввода запроса. Пользователь вводит искомый фрагмент (например, слово "data"). Пользователь может уточнить критерии поиска, выбрав соответствующие опции в интерфейсе:

   * Учет регистра: Если пользователь включает эту опцию, система будет различать заглавные и строчные буквы (например, «Текст» и «текст» будут считаться разными словами).

   * Слово целиком: Если пользователь выбирает эту опцию, система будет искать только полные совпадения, игнорируя части слов (например, поиск «код» не найдет это сочетание внутри слова «кодировка»).

3. Выполнение поиска: После подтверждения ввода система мгновенно анализирует всё содержимое документа. Она проверяет каждое слово в тексте на соответствие введенному запросу, учитывая выбранные пользователем ограничения (регистр и границы слов).

4. Визуализация результатов (Подсветка): Система обновляет отображение документа в основном окне редактора:

   * Все найденные совпадения автоматически выделяются ярким фоновым цветом (например, оранжевым), чтобы пользователь мог мгновенно заметить их в массиве текста.

   * Подсветка поиска накладывается «поверх» существующего форматирования. Если слово имело синтаксическую раскраску (например, было синим как ключевое слово), оно остается синим, но получает цветной фон. Это позволяет пользователю видеть и результат поиска, и контекст кода одновременно.

5. Просмотр документа: Пользователь просматривает документ с выделенными результатами. Текст остается доступным для чтения и навигации.

6. Завершение режима поиска: Когда пользователь заканчивает работу с результатами (например, очищает поле поиска или нажимает «Сброс»), система убирает фоновое выделение. Документ возвращается к своему исходному виду, сохраняя только базовую подсветку синтаксиса.

# Успешный сценарий

1. Пользователь через пользовательский интерфейс вводит текст, который необходимо вставить
2. С помощью тега '<p>' пользователь может создавать новый абзац, в ином случае текст будет записываться в последний абзац 
3. После успешной вставки текста пользователь выводит содержимое документа на экран в таком виде, в котором он его вводил.

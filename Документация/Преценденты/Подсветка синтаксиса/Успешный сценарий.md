1. Пользователь открывает документ и инициирует подсветку
2. Редактор создаёт стратегию подсветки и применяет её к документу. 
3. Контроллер обращается к фабрике для получения стратеги1 подсветки
4. Пользователь выбирает стратегию
5. Контроллер передаёт стратегию документу для рекурсивной обработки
6. Стратегия последовательно вызывается для каждого элемента документа от корня к листу
7. После рекурсивного применения форматирования контроллер запрашивает отрисовку документа
8. При отрисовке документ запрашивает у каждого слова его текущий стиль рендеринга

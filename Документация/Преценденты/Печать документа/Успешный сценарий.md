УСПЕШНЫЙ СЦЕНАРИЙ: 
1. Запрос печати:Пользователь выбирает в меню команду «Печать»
2. Ввод параметров:
Система отображает диалог настроек печати. Пользователь указывает:Принтер (например, «HP_LaserJet»),Количество копий (например, 1),Диапазон страниц (например, «1-5»),Режим дуплекса (например, «Да»),Ориентацию (например, «Книжная»
3. Обработка:Система создаёт объект PrintSettings с указанными параметрами. Затем вызывает метод printDocument() в редакторе, передавая ему текущий документ и настройки.
4. Генерация предварительного просмотра (опционально):
Система может автоматически сгенерировать предварительный просмотр: Вызывает PrintManager.showPreview(document, settings),PrintManager делегирует задачу PrintPreview.generatePreview(), PrintPreview получает текст из Document.getText(),
5. Отправка на печать:Система вызывает PrintManager.print(document, settings). PrintManager передаёт задание объекту Printer.send_to_print(document, settings).
6. Завершение работы:
Система возвращает управление пользователю. Документ остаётся открытым, состояние редактора не меняется.
